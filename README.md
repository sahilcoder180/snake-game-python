# 🐍 Snake Game Python - Mobile Edition

Classic Nokia-style Snake Game made in Python using Pygame 🎮

### ✨ Features:
- Full screen mobile gameplay 📱
- Green grass background 🌿 
- Touch Left/Right controls 👆
- Score tracking system 🏆
- Super smooth performance

### 🎮 How to Play:
Tap left side of screen = Move Left  
Tap right side of screen = Move Right  
Eat food, grow longer, don't hit walls!
